# 06. Visual Direction — Bluetick Digital

## 1. Aesthetic Identity: Swiss Architectural Style
Bluetick Digital 2.5 uses an **Editorial Architecture & Engineering Studio** design language.

### Core Principles
1. **Grid as Visible Structure:** Column alignment, hairline dividers (`rgba(15, 23, 42, 0.08)`), and asymmetric split layouts (`60/40`, `70/30`).
2. **Typography as Hierarchy:** `Plus Jakarta Sans` ExtraBold (`800`) display titles with tight tracking (`-0.035em`) doing the heavy lifting instead of unnecessary glow effects.
3. **Numeric Sequence Markers:** Explicit section markers (`01 /` through `06 /`) establishing architectural order.
4. **Hairline Border Lists:** Replacing repetitive rounded card containers with clean horizontal border dividers (`.border-list`, `.border-list-item`).
5. **Controlled Color Contrast:** Neutral off-white canvas (`#ffffff` / `#f8fafc`), deep charcoal slate text (`#0f172a`), and high-contrast electric brand blue (`#1d4ed8`) CTAs.
